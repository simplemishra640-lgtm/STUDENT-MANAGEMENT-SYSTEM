# 🎓 Student Management System

A simple Student Management System built with Python that stores student records in a JSON file. This project allows users to manage student information through an easy-to-use command-line interface.

## ✨ Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- ✏️ Update Student Details
- ❌ Delete Student
- 💾 Automatic JSON Data Storage

## 🛠️ Technologies Used

- Python
- JSON

## 📂 Files

- `student_management.py` – Main Python program
- `students.json` – Stores student records
- `README.md`

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Run the program:

```bash
python student_management.py
```
